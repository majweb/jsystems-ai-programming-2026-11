- Metric resolution (VERIFIED from paper text, arXiv 2412.17933 Section 4.3 and HF blog, via summariser):

  - Appendix B: "employs a Duel Win Score (DWS) mechanism that statistically compares each model against others"

  - HF blog: "Macro-averaged model win-rate!"
  - Conclusion: the Avg column is a percentage win rate, so 49.5 is NOT an accuracy and cannot be compared directly with accuracy numbers from other benchmarks.
- Rank: caption and text both say 21st ("placing it at position 21 among evaluated models"). Table row order is not a rank; do not read rank from row order.
- English comparison: none. No GPT model in the table.
- Source (primary): https://arxiv.org/html/2505.02410 (Appendix B, read at offset 100000); https://arxiv.org/html/2412.17933v2
- Verbatim snippet: "Bielik-11B-v2.3-Instruct 11.2 49.5 46.9 31.0 48.7 25.9 54.6 67.1 64.2 57.4"
- Verification status: row and 49.5 VERIFIED; metric VERIFIED; rank 21 VERIFIED as stated in the paper (not derivable from row order)
- Confidence: high for 49.5 as a DWS win rate; low for interpreting the 90.2 vs 49.5 gap as accuracy
